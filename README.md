# 六爻书房 · liuyao-study

六爻排盘、学习与卦例记录工具。纸本 / 江南 / 墨玉三主题，本地数据，不需要服务器。

## 这是什么

给六爻学者自用的桌面工具：真排盘（《古筮真诠》十三神煞、23:00 子时换日）、软件内重排阅读（13 本藏书 + 4 份笔记）、卦例记录与回访、录音课页、历法罗盘。

## 下载与更新

安装包与更新都通过本仓库的 [Releases](https://github.com/fengye126/liuyao-study/releases) 发布：

- 下载最新安装包：见 Releases 页最新版本；
- 应用内的「检查更新」会读取本仓库的 Releases，有新版本时提示下载；
- 不需要 GitHub 账号即可下载（仓库为公开，仅分发程序，不包含任何书籍、录音、卦例等个人资料）。

## 隐私

书、录音、卦例、备份都只保存在使用者本机；本仓库不接收、不存储这些内容。

## 状态

正在开发中。版本记录见 Releases。
