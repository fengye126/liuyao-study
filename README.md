# 六爻书房 · liuyao-study

六爻排盘、学习与卦例记录工具。纸本 / 江南 / 墨玉三主题，本地数据，不需要服务器。

## 这是什么

给六爻学者自用的桌面工具：真排盘（《古筮真诠》十三神煞、23:00 子时换日）、书内排版阅读（13 本藏书 + 4 份笔记，需自备资料导入）、卦例记录与回访、录音课页、历法罗盘、学习空间（摘录笔记 / 书课互链 / 阅读进度）。

## 下载与更新

安装包与更新都通过本仓库的 [Releases](https://github.com/fengye126/liuyao-study/releases) 发布：

- 下载最新安装包：见 Releases 页最新版本；
- 应用内的「检查更新」会读取本仓库的 Releases，有新版本时提示下载；
- 不需要 GitHub 账号即可下载（仓库为公开，仅分发程序，不包含任何书籍、录音、卦例等个人资料）。

## v0.4.0 更新要点

- 学习空间：读取时选中文字即可摘录→写笔记，学习空间新增「笔记库」（新建 / 编辑 / 删除 / 搜索 / 按出处分组 / 导出 Markdown 与文本）；
- 课页音频同步：有整理稿的课（第 26 课）段落随播放高亮、点段落跳音频、上一句 / 下一句、0.75–2× 倍速；
- 书与课互链：课页「书中原文」直接跳书页；书页卦例显示「同卦讲解」进对应课程；
- 阅读进度：书架按在读排序，进度条 + 百分比 + 当前章节；
- 书系标注：13 本标注体系 / 类型 / 难易，可切换「学习顺序」；
- 排盘：切换起卦模式或改选六爻时自动开始新一卦，不再出现旧盘面残留、也不再被「盘面已生成」卡住；
- 图标：线装书 logo 接入安装包、窗口与软件内标识。

## 从源码构建

```bash
cd app
npm install
npm run dist
```

需要 Node.js 20+ 与 Windows 环境；安装包不含书籍与录音，书籍/录音在应用内「导入资料」选择本地文件夹即可。

## 隐私

书、录音、卦例、备份都只保存在使用者本机；本仓库不接收、不存储这些内容。
